# Java 常见概念

## 接口与抽象类

Java 中接口(interface)与抽象类(abstract class)都用于抽象,但有明显区别。一个类只能继承一个抽象类,但可以实现多个接口。抽象类可以有成员变量、构造方法与已实现的方法;接口在 Java 8 之后可以包含 default 方法与静态方法,但仍不能有实例字段(常量除外)。

选择原则:如果需要复用实现细节或表达"is-a"关系,使用抽象类;如果只约定行为契约、希望支持多实现,使用接口。

## JVM 内存区域

Java 虚拟机把运行时内存划分为若干区域:堆(Heap)存放对象实例,是所有线程共享的区域,也是垃圾回收的主要对象;虚拟机栈与本地方法栈存放方法调用的栈帧(局部变量表、操作数栈等),随线程创建与销毁;方法区(Metaspace)存放类元信息与运行时常量池;程序计数器记录当前线程执行的字节码位置。

堆内存不足时会抛出 `OutOfMemoryError: Java heap space`,栈深度超出限制时抛出 `StackOverflowError`。理解各区域的生命周期与溢出场景,有助于定位线上内存问题。

## 垃圾回收算法

常见的垃圾回收算法包括标记-清除、复制与标记-整理。标记-清除实现简单但会产生内存碎片;复制算法把存活对象搬到另一半空间,适合新生代这类对象存活率低的区域;标记-整理在清除后整理存活对象,适合老年代。

现代 JVM 使用分代收集:新生代默认采用复制算法(如 Parallel Scavenge),老年代采用标记-整理或标记-清除(G1 则是按 Region 回收)。吞吐量优先场景适合 Parallel GC,低延迟场景可选 G1 或 ZGC。
