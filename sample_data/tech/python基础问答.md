# Python 基础问答

## 装饰器

装饰器(Decorator)是 Python 中一种在函数或类定义时修改其行为的语法。它本质上是一个接收函数作为参数、返回新函数的高阶函数。常见的用法包括日志记录、权限校验、缓存与计时。

使用 `@decorator_name` 写在目标函数定义上方即可应用。例如一个简单的计时装饰器可以先记录开始时间,调用原函数,再计算耗时并打印。多个装饰器可以叠加,应用顺序是自下而上:最靠近函数定义的那个装饰器最先执行。

需要注意的是,装饰器会在函数定义时立即执行外层逻辑,如果需要在运行时才执行,应把逻辑包装在内部函数中并通过 `functools.wraps` 保留原函数的元信息(如 `__name__` 与文档字符串)。

## 生成器与 yield

生成器是使用 `yield` 关键字的函数,调用它不会立即执行函数体,而是返回一个生成器对象。每次通过 `next()` 或 for 循环迭代时,函数会从上次 `yield` 的位置继续执行,直到再次遇到 `yield` 或函数结束。

生成器的主要优势是惰性求值:它可以逐个产出值而不需要一次性把所有结果放进内存,适合处理大文件、无限序列与流式数据。当生成器函数执行完毕或遇到 `return` 时,迭代会抛出 `StopIteration` 异常(在 for 循环中被自动处理)。

此外,生成器支持 `send()` 方法向内部传值,`close()` 方法提前终止,以及 `yield from` 语法把迭代委托给另一个可迭代对象。
